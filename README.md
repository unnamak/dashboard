# A&I Quality Engineering Dashboard

An interactive quality engineering dashboard for analyzing and visualizing QA metrics, execution data, and estate workbooks.

## Features

- **Excel Data Processing**: Drag-and-drop support for QA estate workbooks and QMetry extracts (`.xlsx`, `.xlsm`, `.csv`).
- **Interactive Views**: Visual breakdowns of execution metrics, test runs, and quality indicators across Run, Grow, and Transform dimensions.
- **Export & Reporting**: Built-in functionality to download snapshots as images.
- **Filtering & Breakdown**: Dynamic filtering by teams, squads, test types, and statuses.

## Getting Started

1. Open `AI_QA_Dashboard_latest.html` directly in any modern web browser.
2. Load your QA data workbook or sample files:
   - `Sample_QA_Estate_Workbook_2.xlsx`
   - `QMetry_Extract_Sample_BU_Matched_2.xlsx`
3. Explore the visual analytics and metrics.
